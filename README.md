# Mural dos Sonhos

App para transformar uma visão de futuro em pequenos passos possíveis. Identidade visual em tons pastéis inspirada em scrapbook.

## Desenvolvimento

Requer Node.js compatível com Vite 8 (22.12+ ou 24+).

```sh
npm install
npm run dev
npm run build
npm run lint
```

## Estado atual

Primeira prévia: perguntas adaptativas por regras, sonho principal, meta, próxima ação, conclusão da ação e visualização guiada em texto. Rascunhos ficam no localStorage deste navegador, sem autenticação. Não é um beta público nem uma garantia de armazenamento privado. Não inserir dados sensíveis.

Ainda pendentes: Supabase, autenticação, arquivos privados, mural de imagens, PWA, testes de permissões e preparação jurídica para público a partir de 16 anos.
